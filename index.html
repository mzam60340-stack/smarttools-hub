Install SmartTools Hub on your phone

No Play Store, no download waiting. SmartTools Hub is a real installable web app (PWA) — manifest, service worker and offline support included. Install it straight from Chrome in under 30 seconds.

Checking install support…
  1. Open this site in Chrome on Android.
  2. Tap Install app above when it appears — or use the ⋮ menu.
  3. Tap “Install app” / “Add to Home screen” → Install.
  4. Done — open SmartTools Hub from your home screen anytime, even offline after your first visit.

On desktop Chrome/Edge, use the install icon in the address bar. On iPhone Safari: Share → Add to Home Screen.

Questions

Is SmartTools Hub really free?

Yes. Every tool is free with no sign-up and no usage limit. The plan is to keep it free and cover costs with advertising (Google AdSense) once the site qualifies.

Is my data private? What leaves my device?

Your tool inputs stay on your device. Passwords you generate, numbers you calculate, text you paste and images you compress are processed in your browser by this page's own code — they are not uploaded to a SmartTools Hub server (there is no backend server) and are not saved after you close the tab, except the small app cache the installed PWA keeps so it can open offline.

What does leave your device: loading this page makes normal web requests to outside providers — Google Fonts (fonts.googleapis.com / fonts.gstatic.com, for the typeface) and cdnjs (cdnjs.cloudflare.com, for the QR code library). Those providers receive the usual request data, such as your IP address and browser details, under their own privacy policies. If those requests are blocked or you're offline, the tools still work except QR generation, which needs its library loaded once.

Does it work offline and on Android?

Yes. It works in any mobile browser, and you can install it as a real PWA (see the install steps above) — after the first visit the installed app opens offline for the tools that don't need an external library. A native Play Store app with AdMob is a later step in the roadmap, not required to start.

Which tool should I try first?

The most-used tools are the Loan / EMI Calculator, Password Generator, BMI Calculator and QR Code Generator — all marked “Popular” in the grid above.
