Install SmartTools Hub on your phone

No Play Store, no download waiting. Install it straight from Chrome in under 30 seconds — it lands on your home screen like a normal app.

  1. Open this site in Chrome on Android.
  2. Tap the ⋮ menu in the top-right corner.
  3. Tap “Add to Home screen” → Install.
  4. Done — open SmartTools Hub from your home screen anytime.

On desktop Chrome/Edge, use the install icon in the address bar for the same result.

Questions

Is SmartTools Hub really free?

Yes. Every tool is free with no sign-up and no usage limit. The plan is to keep it free and cover costs with advertising (Google AdSense) once the site qualifies.

Is my data private?

Yes — all tools run entirely in your browser. Passwords you generate, numbers you calculate and text you paste are never sent to a server or saved anywhere.

Does it work on Android?

Yes. It works in any mobile browser, and you can install it to your home screen as a PWA (see the install steps above). A native Play Store app with AdMob is a later step in the roadmap, not required to start.

Which tool should I try first?

The most-used tools are the Loan / EMI Calculator, Password Generator, BMI Calculator and QR Code Generator — all marked “Popular” in the grid above.
